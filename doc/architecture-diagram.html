Data Flow Summary

  1. Injected Script monkey-patches fetch & XHR to intercept comment POST to /supportapi/zd/.../tickets/{id}/comments
  2. Captured comment sent to Content Script via window.postMessage (cross-world bridge)
  3. Content Script forwards to Background Service Worker via chrome.runtime.sendMessage
  4. Background stores in chrome.storage.local (deduplication, tagging, date-grouping)
  5. Background sends to Native Host via Native Messaging (4-byte header protocol)
  6. Native Host writes formatted .md files to local filesystem (Year-Month/ hierarchy)
  7. Popup UI queries Background for captured comments, settings, and tag management
